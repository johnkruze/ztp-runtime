| target | clock | dt | ethic |
|--------|-------|----|-------|
| `hold` | 1 kHz | 0.001 s | do not drop the part (45 N clamp) |
| `tissue` | 1 kHz | 0.001 s | do not destroy the sample (1.2 N liver) |

```
cd ztp-runtime

```
